This past month I have been study about Kubernetes both for my skillsets as Engineer and Work, I started around June where I should have been learning more about [Podman](% post_url 2026-04-09-pain-and-suffering-with-podman %) because I want to know more about how container and Podman work as alternative to Docker but instead I pivot to Kubernetes because I saw book with title "Kubernetes in Action".

[Yes](https://youtu.be/sq_Fm7qfRQk) I learn about Podman and Kubernetes through books because the creator of Podman [Daniel Walsh](https://www.redhat.com/en/authors/daniel-walsh) write books about Podman named "Podman in Action" with Manning Publications. I knew about the books from his blog in Red Hat talking about the feature in Podman and then I fainly remember that he write book about Podman so I went to check it and then proceed to download through libgen start reading it.

From the book I learn how Docker and Container works and also how does Linux Kernel managing the container through cgroup and namespace, for me the most interesting part is that Docker managing the container from pulling the image through registry and run it with their runtime as unison but since Docker is daemon and any failed through the process can have impact in other component of the Docker.
